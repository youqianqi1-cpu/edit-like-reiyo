# 剪出帧我 · Edit like Reiyo

像 Reiyo 一样，剪出有活人感的 IP 视频。

把自由剪辑师 Reiyo 的剪辑判断交给 Codex：从重说里选完整的一遍，精细收紧气口，让字幕、大字、景别、真实素材和声音跟着表达发生。保留你自己的语气、观点和审美偏好。也可以只让它看片，提出文案、拍摄和剪辑建议。

这是免费试用版，适合已经在使用 Codex、电脑上已安装剪映专业版的创作者。第一轮请准备真人口播；纯录屏教学、复杂 Vlog 或剧情片需要另外确认处理范围。

## 第一次怎么用

1. 下载并解压整个包。新建一个“视频试剪”文件夹，把 `edit-like-reiyo` 文件夹、原视频和愿意使用的配图/录屏放进去。不要只复制 `SKILL.md`。
2. 在 Codex 中打开“视频试剪”文件夹，开一个新聊天，把下面的话粘进去。首次测试先不带旧聊天；已有字幕偏好可以直接告诉它。
3. Codex 先检查电脑条件。Windows 首次需要下载本地工具和语音识别模型，会先告诉你再准备；识别在本机进行。下载失败就把提示反馈回来，不需要自己反复换办法。
4. 条件满足后开始剪。当前 Codex 没有电脑操作能力时，它会请你在剪映新建、命名一个空白草稿并回到首页，之后再使用本地工具写入。最后由你打开新草稿播放确认。
5. 在剪映查看以“剪出帧我试剪”开头的新草稿；原片和已有草稿保留。默认不额外导出视频。

## 直接发给 Codex

```text
请使用文件夹里的 edit-like-reiyo/SKILL.md，按它的说明完成一次真人口播试剪。

先检查本机运行条件、剪映版本及你实际能用的电脑操作工具。Windows 按包内说明走实验入口；第一次先做一个新草稿里的短段，确认能保存重开、画面字幕正常，再继续全片。如果需要下载本地工具或模型，一次告诉我需要什么、放在哪里，再开始准备。不要升级系统或降级剪映。

原视频和可用配图都在当前文件夹。完整保留我的独有观点，按 Skill 处理重说、气口、字幕、景别、音效和合适的画面。不要参考以前的聊天、旧剪点或作者电脑上的其他工具。需要补充素材或确认偏好时，集中问我一次。

新建“剪出帧我试剪-视频名”草稿，原片和已有草稿不动。如果你没有操作剪映窗口的能力，告诉我需要手动完成的最少步骤；不要声称已经替我点击或播放。

保存可编辑草稿即可，不用导出。最后告诉我草稿名、用时、做了哪些处理，以及哪些地方还需要我看听确认。
```

## 怎么反馈

告诉 Reiyo：电脑和剪映版本、能否顺利完成、总用时，以及一个最满意或最想修改的片段（带时间点或录屏）。比较额度时，开始前后各截一次 Codex 额度页面，并注明期间有没有同时跑别的任务。

这次试用关注“拿到后是否能顺利剪”和“成片是否愿意用”，不要求你写长报告。不要把整台电脑的素材、账号信息或私人聊天一起打包反馈。

## 包里有什么

- `edit-like-reiyo/SKILL.md`：剪辑流程和判断入口。
- `references/`：气口、字幕、音效、画面、素材选择与课程案例。
- `scripts/`：执行这些判断的配套工具，不替创作者决定观点。

详细运行范围见完整包内的 `edit-like-reiyo/references/compatibility.md`。免费试用不需要上传你的原视频到 GitHub。作者：[ReiyoLab](https://reiyolab.com)。
